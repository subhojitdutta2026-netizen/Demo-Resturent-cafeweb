# Sizzle & Craft - Gourmet Grill & Bistro Website

A modern, responsive, and fully interactive restaurant landing page and digital ordering system.

## 🍔 Features Included
- **Hero Section**: Showcasing the custom gourmet burger with dynamic 3D drop-shadows and interactive Chef's Special ordering badge.
- **Floating WhatsApp Order/Support Widget**:
  - Direct WhatsApp chat popup and click-to-chat button
  - Connected to phone number: **+91 99070 23875** (https://wa.me/919907023875)
- **Indian Rupee (₹) Pricing**: All dishes and billing in INR (₹).
- **Interactive Slide-Out Cart**:
  - Real-time quantity adjustments, tax calculations, free delivery threshold
  - One-click checkout directly to WhatsApp with pre-filled itemized order details
- **Digital Interactive Menu**:
  - Filter by Burgers, Steaks, Platters, and Drinks/Desserts
  - Quick 'Add to Order' functionality
- **Table Reservation System**:
  - Date, time slot, and guest count selector
  - Instant booking confirmation modal
- **Live Order Tracker**:
  - Step-by-step cooking and delivery timeline
- **Dish Gallery Lightbox**:
  - Fullscreen view with dish tasting notes

## 📁 File Structure
- `index.html`: Main landing page (production ready)
- `code.html`: Source HTML/CSS/JS file
- `hero-burger.png`: High-resolution transparent PNG burger asset
- `screen.png`: Reference preview image
- `DESIGN.md`: Design system guidelines and color palette
- `server.ps1`: Local preview server script (PowerShell)

## 🚀 How to Run Locally
### Option 1 (Directly in Browser):
Double-click `index.html` to open it in any web browser (Chrome, Edge, Firefox, Brave).

### Option 2 (Local Server):
Right-click `server.ps1` and select **Run with PowerShell**, or in terminal:
```powershell
powershell -ExecutionPolicy Bypass -File server.ps1
```
Then visit: **http://localhost:8080/**
